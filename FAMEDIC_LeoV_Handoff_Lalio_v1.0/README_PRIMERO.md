# Paquete FAMEDIC–LeoV para Lalio v1.0

## Convención
**LeoV** = asistente virtual FAMEDIC. Se utiliza este alias para evitar confusión con el nombre de Lalio/Leo.

## Orden de lectura
1. `01_Documento_Rector/Handoff_Tecnico_Funcional_FAMEDIC_LeoV_para_Lalio_v1.0.pdf`
2. `02_Matrices/Matriz_Brechas_APIs_Plataforma_FAMEDIC_LeoV_v1.0.xlsx`
3. `03_Requerimientos_API/Requerimientos_Contratos_API_FAMEDIC_LeoV_v1.0.md`
4. `02_Matrices/Checklist_Aceptacion_MVP_FAMEDIC_LeoV_v1.0.xlsx`
5. Documentación funcional y API actual como anexos.

## Objetivo de la devolución de Lalio
- Respuestas a las preguntas de decisión.
- Estimación y responsables por requerimiento.
- OpenAPI/Postman consolidados.
- Evidencia de seguridad, idempotencia, titularidad y OTP SMS.
- Resultado del checklist de aceptación.
- Lista definitiva de capacidades habilitadas para LeoV.

## Nota
Los archivos funcionales v0.1 son insumos de referencia y deberán evolucionar a v1.0 después de cerrar las decisiones técnicas. No debe asumirse que toda capacidad descrita está ya liberada.
